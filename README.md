# The `Dre!` Programming Language

I wanted to create a programming language that is flexible, versatile, strict, and powerfull, reflecting the traits of its author. It is statically and strongly typed, both procedural and functional, with object-oriented support. I've called it `“Dre”`, an acronym for the phrase: *"Don't Rely on Emotion"*. The `!` is added for the emphasiness of the attitude, since relying on emotion is a bloody bad idea, so we should always be rational when dealing with anything. The name also has a nice ring to it, and it's short and easy to remember.

The main goal of this project is the embodiment of a programming language with such traits, serving for a hobby project, a resource for educators, and a framework for researchers.

Some key characteristics and features of the language:
- Beautiful, precise, and expressive syntax.
- Every line *should* have one and only one meaning.
- There *should* be only one way to do something (I don't want garbage in my language!).
