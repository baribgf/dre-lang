# The `Ima` Programming Language

I wanted to create a programming language that is beautiful yet powerfull. It is statically and strongly typed, both procedural and functional, with object-oriented support. I called it `“Ima”` (for some reason). You can treat the name as a backronym for the phrase: "Intrinsic Manipulation of Abstractions".

The main goal of this project is the embodiment of what is meant by a `“beautiful”` programming language. Moreover, It'll serve for a hobby project, a resource for educators, and a framework for researchers.

Some key characteristics and features of the language:
- Beautiful, precise, and expressive syntax.
- Every line *should* have one and only one meaning.
